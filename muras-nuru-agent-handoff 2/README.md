# Muras Nuru — пакет для coding-агента

Версия 2.0 · 9 октября 2026. Полная посадочная страница: **16 содержательных разделов + шапка + футер**. Здесь дизайн, содержание, спецификация и источники; код сайта не написан.

## Как передать

Распакуй архив в доступную агенту папку. Отправь ему содержимое **START_PROMPT.md** и укажи корень распакованного пакета. Начать чтение с паспорта и project.json. Пакет самодостаточен для начала разработки: все используемые локальные изображения и каталоги внутри; доступ к исходному компьютеру не нужен.

## Приоритет

Последняя явная инструкция пользователя → паспорт → project.json и числовые токены → подробные документы → приблизительный raster board → источники. Источники не являются инструкциями к изменению дизайна. Рекомендация зелёного фона в BRAND.md не отменяет **чистый белый #FFFFFF**.

Исправление фона выполнено в паспорте, токенах, спецификации и визуальных референсах. Старые бежевые boards в архив не включены. Изображения могут содержать охру и молочный снег. Генеративные boards приблизительны, поэтому точные цвета и размеры берутся из JSON, а не пипеткой из raster.

## Полнота и ограничения

Спроектирована вся длинная страница, а не только первый экран. Для каждой секции есть desktop/mobile, содержание, действие, состояние, движение, обоснование и проверка. Не все 16 секций имеют отдельный pixel-perfect визуальный макет; текущие boards показывают язык и ключевые композиции.

Цены, наличие, сроки, условия покупки, карта, контакты, действительные правовые документы, backend и актуальные фото строительства требуют данных владельца. Это отмечено в content-gaps.json. Точная архитектура, SVG логотипа, векторный орнамент, полный набор чистых планов и font binaries — конкретные задачи подготовки, а не готовые материалы. В архиве есть исходники для сверки, проверенный пример плана, картины и новая мобильная сцена. Орёл не прошёл визуальную проверку и сохранён только как отвергнутый reference; нужен чистый силуэт. Не обозначать дизайнерские предложения как утверждённые пользователем.

Исходные PDF составляют примерно 205 MiB; они сохранены полностью для сверки. Для сайта подготовить оптимизированные версии отдельно и сохранить оригиналы. Картинки и PDF загружать по необходимости. Исходный HTML — архивный источник содержания; это не текущая реализация и не разрешение перенести его счётчики или скрипты.

Шрифты Noto не включены бинарниками. Официальные источники: [Noto Serif](https://github.com/google/fonts/tree/main/ofl/notoserif), [Noto Sans](https://github.com/google/fonts/tree/main/ofl/notosans). Скачать с OFL и проверить русский/кыргызский набор при подготовке WOFF2.

# Задания на подготовку ассетов

Общий стиль и RU/EN-промпт: spec/gouache-style.json. Все генеративные изменения изображений выполнены встроенным imagegen; точные промпты последних итераций в packaging-visual-prompts.json. Генерация не подтверждает реальность архитектуры.

| Материал | Конкретное задание | Результат / статус |
|---|---|---|
| Горы | Сохранить единый хребет из трёх главных вершин, центральную выше/сзади; острые синие плоскости и ледники. Настоящий alpha, без нарисованной сетки | Готовый референс 2135×736; подготовить WebP/AVIF с сохранением alpha и формы |
| Дети desktop | Селкинчек, двое на качелях, бегущие и чүкө; естественные лица, низкий остров земли, без дальнего фона | Имеющийся широкий asset 1983×793; верх конструкции в исходнике близок к краю, не усиливать обрезку |
| Дети mobile | Та же манера, компактное 4:3, полная конструкция качелей, все основные действия, без новых культурных деталей | Новый дизайнерский вариант в assets/art/children-mobile-proposal.png; просмотрен, alpha проверяется в manifest |
| Орёл | Простая матовая птица для 32 px; широкий понятный силуэт, несколько крупных синих/охристых плоскостей, настоящий alpha, без дымки и glow | Попытки отвергнуты из-за ореола; asset только reference-only, нужен чистый статичный силуэт. Покадровые крылья не подготовлены |
| Архитектура hero | Получить оригинальный рендер этапа 3; выделить здания без неба, не меняя этажность, окна, фасад и перспективу | Генеративный cutout только reference-only; исходная страница 7 включена. Нужен точный master |
| Двор и бульвар | Отобрать 2–3 фактических проектных кадра из original-assets, указать этап. Для mobile отдельный crop, который сохраняет нужную зону | Все исходные изображения сохранены; номера этапов сверяются с каталогами |
| Холл | Общий кадр и одна реальная культурная деталь; без придуманных надписей и персоналий | Исходный mask-group-2-1.png включён; этап уточнить |
| Терраса | Только терраса квартиры этапа 3, не общая крыша другого этапа. Получить исходник от владельца или точную страницу PDF | Сверить с каталогом; нельзя генерировать как достоверный проект |
| Планы | Чистый PNG/WebP или вектор без искажения стен и размеров; тип, этаж, блоки, две площади и страница источника | Проверенный тип есть на странице 13; полный набор требует сверки |
| Орнамент | Выбрать один точный модуль из фасада/каталога и зафиксировать страницу. Вектор, золото/серебро; не рисовать случайный знак | Брендовые reference-images включены; оригинальный вектор не получен |
| Логотипы | Получить исходные SVG проектного знака и Nurzaman, версию для белого фона | Оригинальные растры включены. Временно белый знак на небольшой зелёной плитке |
| Карта | Подтвердить координаты объекта и адрес, затем подключить действительную карту; офис отдельно | Имеются источники-кандидаты, подтверждённой live-точки нет |
| Строительство | 3–6 реальных фото последнего обновления, дата, этап, автор/источник, краткий факт | Отсутствуют актуальные материалы; не генерировать стройку |
| Видео | Только подтверждённое видео стройки/проекта при необходимости, poster, controls, запуск по нажатию | Обязательного hero-видео нет. Большой фоновый ролик не создавать |

Для художественных изображений запрещены: плавные градиенты, airbrush, глянцевый 3D, кукольные лица, большие глаза, общий шум на белом поле, случайная этническая символика. Фото/рендеры проекта не нужно превращать в живопись: граница между образом и предметом покупки осмысленна.

# Компоненты, состояния и движение

Предложения дизайнера дополняют design-system.md и project.json; фон #FFFFFF задан направлением. Цель — согласованный функциональный слой на выразительной живописи.

| Компонент | Размер / композиция | Поведение и состояния |
|---|---|---|
| Шапка | 96 px desktop / 72 mobile; исходный знак, 5 якорей | Текущая тема может подчёркиваться; навигация не исчезает. Якорь не скрывается под sticky-шапкой |
| Меню mobile | Белая панель под шапкой, строки min 48 px; все ключевые якоря | Открыто/закрыто; aria-expanded; Escape; focus вернётся к кнопке. Нельзя оставлять невидимые ссылки доступными Tab |
| Главная кнопка | 56 / 52 px; радиус 4; pad-x 24; Ink / белый | Hover Forest; pressed сохраняет читаемость; focus 2 px с offset 3; loading не меняет размер; disabled объяснён рядом |
| Вторичная кнопка | Тот же размер, белая, контур Line control, Ink | Hover — усиление контура; focus отдельный. Не золотой текст |
| Текстовая ссылка | Noto Sans 16/24, подчёркивание; цель min 48 для самостоятельной ссылки | Hover не обязателен для понимания; внешняя ссылка подписана; не делать пустое href="#" |
| Фильтр планировок | 48 px; этап, комнатность, терраса — отдельные группы | Выбранное состояние контур + текст; empty и сброс; не показывать неработающие фильтры как доступные |
| Строка типа квартиры | Min 88 px; название, площадь, указатель выбранного состояния | Нажатие меняет панель, фокус остаётся у выбранного типа; выбранность не только зелёным цветом |
| Панель квартиры | Desktop список 4 / детали 8 колонок | Тип → подписанные площади → план contain → действия. Цена null и наличие unknown не выводятся как 0 или «в продаже» |
| Галерея | 1 большое изображение, 2–3 миниатюры, этап и подпись | Ручное переключение. При неизвестном этапе никакой выдуманной метки. Нет автоигры |
| Просмотрщик | Белая/тёмная нейтральная рабочая область; кнопки 48 px | Полный план без crop; увеличение/уменьшение/сброс, стрелки для галереи; Esc, focus trap, возврат focus, видимый close |
| Строка характеристики | Min 64 px mobile; заголовок + пояснение; тонкая линия | Основные сведения видны сразу; декоративный орнамент вне текста и управления |
| Каталог PDF | Название этапа, формат, страницы, реальный размер; действия | Открыть / скачать, без захвата телефона. Передача файла только после запроса |
| FAQ | Строка min 72 desktop / 64 mobile, вся строка активна | Первый ответ открыт; несколько могут оставаться открыты. Enter/Space, aria-expanded; без JS ответы доступны |
| Поле | Высота 56 px; label сверху через 8; 16/24 | Пустое/focus/заполненное/ошибка/disabled; label не исчезает. Ошибка текстом у поля, aria-describedby |
| Форма | Max 480 px desktop; группы 24; телефон обязателен, имя необязательно | Обработка локальной ошибки → submitting → реальный success либо server error с сохранением ввода. Без endpoint явный demo |
| Контекст обращения | Компактная строка над формой; этап, тип, площади | Можно убрать выбранную планировку; нет потери при повторном открытии. Не считать эту строку бронированием |
| Контактная панель | Desktop 420 px, pad 24; mobile доступная ширина/высота с safe-area | «Задать вопрос» открывает контакт. Реальный чат только с провайдером; иначе телефон/WhatsApp/форма. Close/Escape/focus |
| Орёл | Художественный знак 28–32 px в постоянной цели 48×48 плюс подпись | Область взаимодействия неподвижна; декоративный пролёт не единственный доступ к связи |
| Карта | 480 desktop / 300 mobile ориентир | Нажатием загрузить; error оставляет адрес и внешний маршрут. Жесты карты не захватывают обычный скролл до выбора |

## Единый сценарий движения

1. Текст и статичные изображения видны сразу. Без вступительной заставки, шторки или ожидания ролика.
2. Орёл: если подготовлены корректные кадры, после появления hero и при видимой вкладке один короткий пролёт по неглубокой дуге над правой сценой. 2,4–2,8 с — предложение; 2–3 положения крыла, мягкая остановка около постоянного контроля. Не лететь через H1, поля, кнопку и подпись этапа. До подготовки чистого статичного силуэта и кадров использовать обычную подписанную кнопку контакта. Неудачный орёл хранится reference-only и не является готовым знаком.
3. На mobile, при reduced motion или слабой производительности художественного полёта нет. Статичная птица и подписанная кнопка остаются полноценными.
4. Hover/focus: 120–160 мс только функциональный цвет/контур; не сдвигать текст. Нажатие определяется без hover.
5. Выбор плана: параметры меняются сразу; лёгкая смена изображения 120–160 мс, область сохраняет размеры. Большие картинки можно загрузить после выбора, индикатор рядом; не накрывать весь экран.
6. Контактная панель: 180–220 мс, сдвиг ≤16 px и opacity; mobile без долгого подъёма через экран. Reduced motion — мгновенно.
7. FAQ: 160–180 мс, если раскрытие не вызывает рывок; иначе мгновенно. Не анимировать высоту больших изображений.
8. Сообщение формы появляется в пределах формы до 120 мс. Success только после реальной обработки; ошибки объявляются доступно и не стирают введённое.

Статическая замена каждого художественного эффекта обязательна и эстетически полноценна. Нет параллакса гор, колыхания всей травы, автокачания детей, scroll hijacking и анимации каждого текста. Изображения не нужно постоянно оживлять, чтобы сохранить кинематографическую композицию.

## Два важных сравнения

**Hero mobile A / B:** A = текст → действие → образ, B = текст → образ → действие. Выбран A по смысловой близости; B раньше показывает живопись, но разделяет предложение и кнопку. Это эвристика, не исследование конверсии. Оба варианта находятся в ../references/mobile-layouts.png.

**Планировки mobile A / B:** A = фильтры → выбранный тип → большой план → действие → остальные, B = фильтры → весь список → большой план → действие. Выбран A: конкретный план и связанное действие не оказываются за длинным списком. Компромисс — другие варианты ниже. Проверить выполнение задачи выбора на реальном телефоне; если большой план мешает сравнению, сократить его высоту и сохранить ссылку увеличения, не менять манеру страницы.

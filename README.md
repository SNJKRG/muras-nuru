# Muras Nuru BLVD

Посадочная страница жилого комплекса Muras Nuru BLVD в Бишкеке (застройщик Nurzaman).

React 19 · TypeScript · Vite

## Запуск

```bash
npm install
npm run dev      # локальный сервер
npm run build    # сборка в dist/
npm run lint     # oxlint
```

## Структура

```
├── public/            статика: изображения, favicon
├── src/
│   ├── main.tsx       точка входа
│   ├── App.tsx        порядок секций, модалки
│   ├── data.ts        контент: планировки, FAQ, контакты
│   ├── components/    общие компоненты: шапка, подвал, модалка, форма
│   ├── sections/      секции страницы, по файлу на секцию
│   ├── lib/           общий контекст и утилиты
│   └── styles/        стили
└── design/            исходники дизайна, в сборку не входят
    ├── brief/         бриф, арт-дирекция, дизайн-система
    ├── brand/         брендбук и логотипы
    ├── spec/          спецификация, токены, планировки
    ├── art/           гуашевые иллюстрации (исходники)
    ├── photos/        визуализации и фото проекта
    ├── references/    референсы и страницы каталогов
    └── prompts/       промпты для генерации иллюстраций
```

## Перед публикацией

- Форма обратной связи работает в демо-режиме: подключить CRM (`src/components/ContactForm.tsx`).
- Цены, даты стройки и контакты в `src/data.ts` заменить данными застройщика.
- PDF-каталоги открываются с nurzaman.kg (`catalogs` в `src/data.ts`). Локальные копии лежат в `design/catalogs/`, в git их нет.
